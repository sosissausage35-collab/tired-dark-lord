A deterministic TypeScript program (Node 22) that writes one 99-word monologue
to `/output/entry.txt` for the make.fun bounty
**The Tired Dark Lord: A 100-Word Villain Monologue**.

## The monologue

Malachar, Ashen King of Karvost — three centuries on the ember throne, keeping
the eclipse rite alive, burying his brother twice. His tiredness lives in the
pauses, the trailing off, and the small deflections — never in a plain claim
that he is weary. The last line keeps the chair by the fire for himself.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Running it twice produces byte-identical output. The entry is 99 words and
533 characters (534 with the trailing newline), inside the 1–600 character gate.
